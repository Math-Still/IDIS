## 一、调研概述与对比总览

赛题明确提出"基于国产操作系统（如统信 UOS、麒麟 OS、OpenHarmony 等）构建智慧工厂安全监测控制平台"，且发榜单位诚迈科技自身深耕国产操作系统（投资成立统信软件、发布工业操作系统 HongZOS）。

本报告调研四个平台，核心结论速览：

| 平台 | 厂商 | 定位 | 内核/底座 | 在工业场景的关键价值 | 对赛题的适配定位 |
| --- | --- | --- | --- | --- | --- |
| 统信 UOS | 统信软件（诚迈科技 2019 年投资成立） | 桌面/服务器/智能终端全栈 | Linux（deepin 系） | 服务器生态成熟、信创适配广、钢铁等重工业产线国产化案例 | 平台层服务器 OS 候选 |
| 麒麟 OS | 麒麟软件（中国电子） | 桌面/服务器/工业版/嵌入式 | Linux | 有**专门工业版**（PREEMPT_RT 实时增强），DCS/SCADA 场景案例 | 平台层服务器 OS 首选之一 |
| OpenHarmony | 开放原子开源基金会 | 万物互联全场景开源操作系统 | 鸿蒙内核 + 自研 | 分布式软总线、端侧生态爆发（10 亿设备），电力/矿山/机器人行业发行版 | 设备侧边缘节点 OS 候选 |
| HongZOS | 诚迈科技 | **工业级** OpenHarmony 商业发行版 | OpenHarmony | 首款工业发行版、工业软总线、Modbus/CAN 协议、官方开发板 | **设备侧首选**（契合发榜单位） |

**一句话结论**：本项目建议采用"**服务器/平台侧 = 统信 UOS 或麒麟 OS（工业版）+ 设备/边缘侧 = 诚迈 HongZOS 或 OpenHarmony**"的双层国产 OS 组合，既满足赛题"国产操作系统为底层环境"的要求，又与发榜单位技术路线深度对齐。

## 二、统信 UOS（统信软件）

### 2.1 厂商背景

- **统信软件技术有限公司**，2019 年由诚迈科技投资成立，总部位于北京，是中国操作系统领域的头部企业。
- 与赛题发榜单位诚迈科技存在直接股权与技术渊源 —— **统信软件是诚迈科技深度参与打造的国产 OS 生态**，这一点可作为参赛方案与发榜单位"同源"的加分叙事。
- 社区底座：deepin（深度操作系统）社区，另设同心生态联盟、统信 UOS 开发者平台（uosdn.uniontech.com）。

### 2.2 产品线

| 产品线 | 说明 |
| --- | --- |
| 统信桌面操作系统 | 专业版 / 教育版 / 社区版 / 家庭版 |
| 统信服务器操作系统（统信有岳） | 面向服务器/云基础设施，V20 系列 |
| 统信云原生操作系统 | 面向云原生场景 |
| 统信智能终端操作系统 | 面向智能终端/边缘设备 |
| 统信容器镜像平台 | 容器化交付支持 |

配套应用产品：统信集中域管平台、统信企业级应用商店、统信 UOS 远舰系统盘、统信云办公等。

### 2.3 服务器操作系统关键特性（统信有岳 V20）

- **强安全性**：符合等保 2.0、可信计算要求，系统内核/应用/主动防御/安全合作四层防护；
- **高稳定性**：稳定版 Linux 内核 + 企业级高可用集群方案；
- **高性能**：面向 AI、大数据、云计算、Web 服务、容器场景的性能调优；
- **易维护**：可视化运维，宣称可提升运维效率 50%；
- **泛兼容**：兼容主流服务器设备与中间件/数据库，适配国内外主流软件包 30000+，累计适配 100000+ 款商业&开源软件；
- **CPU 架构**：支持飞腾、鲲鹏、海光、兆芯、龙芯等国产 CPU 及主流 x86/ARM 平台。

### 2.4 工业场景落地（与赛题相关案例）

- **鞍钢 L2 级产线控制系统国产化**（2026 年报道）：鞍钢数智科技与统信软件联合培训，推动钢铁产线 L2 级控制系统（轧机转速、温度调节、物料输送实时指令）全面国产化，覆盖统信桌面 OS 开发、Qt 框架、服务器 OS 管理、Nginx/Docker 容器化部署 —— 证明统信 UOS 可承载**产线级实时控制**。
- **中煤电气 AI + 统信 UOS**：煤矿安全场景"秒响应"智能监测（巡检替代）。
- **中科可控天阔 W50X + 统信 UOS**：为工业领域打造自主算力基座。

### 2.5 对赛题的价值

- 平台层（服务器）成熟选择：我们的 MQTT、TDengine、规则引擎、大屏服务均可容器化跑在统信服务器 OS 上；
- 桌面/大屏展示：统信桌面 OS 可承载大屏与上位机应用；
- 与诚迈同源，评审叙事加分；
- 获取方式：官网提供镜像下载（chinauos.com/resource/download-server）及免费授权政策（服务器 OS 免费授权）。

## 三、麒麟 OS（麒麟软件）

### 3.1 厂商背景

- **麒麟软件有限公司**，隶属中国电子（CEC）旗下，国产操作系统国家队之一。
- 产品矩阵覆盖桌面、服务器、工业、嵌入式（星光麒麟）、智算全场景，最新主线产品为 **V11 系列**（银河麒麟高级服务器操作系统 V11、银河麒麟桌面操作系统 V11）。

### 3.2 产品线

| 产品线 | 说明 |
| --- | --- |
| 银河麒麟高级服务器操作系统 V10 / V11 | 主线服务器产品 |
| 银河麒麟桌面操作系统 V10 / V11 | 主线桌面产品 |
| **银河麒麟高级服务器操作系统（工业版）V10** | **面向工业研发设计、生产制造场景的服务器 OS**（重点） |
| 银河麒麟桌面操作系统（工业版） | 工业场景桌面版 |
| 银河麒麟云底座操作系统 | 云基础设施 |
| 银河麒麟高可用集群软件 | 高可用 |
| 星光麒麟操作系统 | 嵌入式/物联网 |
| 银河麒麟智算操作系统 | 智算/AI 场景 |

### 3.3 工业版关键特性（银河麒麟高级服务器操作系统（工业版）V10）

> 这是四平台中**唯一有明确"工业版"产品线**的服务器操作系统，与赛题高度对口。

- **国产 CPU 支持**：同源支持飞腾、鲲鹏、海光、兆芯等自主平台，并按平台在内核层/系统层做工业场景优化增强；
- **高效图形显示**：面向国产显卡适配优化，提供高效稳定桌面环境（工业可视化/HMI 可用）；
- **高性能计算**：集成开源 HPC 组件、常用数学库、计算性能分析工具；
- **实时增强**：支持 **PREEMPT_RT 实时内核**，提供实时性瓶颈分析工具 —— 对应赛题"实时响应不足"痛点；
- **可靠安全**：内核热补丁、可信计算、可信执行环境，安全中心 + 安全管理工具 + 安全增强产品 + 安全漏洞管理平台一体化；
- **应用场景**：能源电力（DCS、SCADA、电力调度）、工业制造（研发设计、模拟仿真、生产制造）、公共交通（边缘服务器）、数字通信（智能网关）。

### 3.4 工业落地案例

- **华电芜湖电厂**：国内首套超超临界火电机组自主安全 DCS（基于银河麒麟 + PK 体系 + 可信计算 + 国密算法），覆盖现场层/实时控制层/监控层/厂级管理层；
- **新疆某大型石油炼化企业**：基于飞腾 + 银河麒麟 + 综合可视化平台 FSmartWorx + 实时历史数据库 pSpace 的工业综合可视化方案；
- 工业版已入驻华为云"云商店"，生态伙伴方案成熟。

### 3.5 对赛题的价值

- **工业版服务器 OS 首选**：PREEMPT_RT 实时增强 + DCS/SCADA 场景背书，直接回应赛题"实时响应不足"与"工控系统安全"要求；
- 平台层全栈（数据库、消息、可视化、AI 推理）可在其上运行；
- 获取方式：官网试用申请（400-089-1870）、开发者中心 developer.kylinos.cn、文档中心 document.kylinos.cn。

## 四、OpenHarmony（开源鸿蒙）

### 4.1 项目定位

- **开放原子开源基金会（OpenAtom）孵化及运营**的开源项目，目标面向全场景、全连接、全智能时代，搭建智能终端设备操作系统框架与平台。
- 官方门户：openharmony.cn；代码托管：Gitee。

### 4.2 版本演进与生态规模（截至调研时）

| 指标 | 数据 |
| --- | --- |
| OpenHarmony 1.0 Release | 约 700 万行代码，仅支持传感器、摄像头等无屏简单设备 |
| **OpenHarmony 5.0 Release**（2025 年 1 月发布） | **超 1.2 亿行代码**，底座及配套能力快速稳定成熟 |
| 生态设备 | 以开源鸿蒙为底座的生态设备数量**突破 10 亿** |
| 芯片适配 | 与主流芯片厂商合作，完成**超 120 款芯片**适配 |
| 产品兼容 | 超 900 款软硬件产品通过兼容性测评 |

5.0 版本能力：系统完备度显著提升，支持各类超级应用开发；**分布式软总线再升级**（设备连接效率与稳定性提升）；多任务处理更高效、设备间数据共享更安全便捷；开发者环境更友好。

### 4.3 工业行业应用（对赛题最关键）

开源鸿蒙正"下沉"产业一线，已覆盖电力、交通、医疗、金融等基础行业：

- **电鸿（电力鸿蒙）**：华为开发者社区发布，开源鸿蒙底座重构新型电力系统全链路技术体系；
- **矿鸿（矿山鸿蒙）**：煤炭行业智能矿山场景（诚迈科技亦有矿鸿生态成果，见下节）；
- **边缘网关产品化**：研华首款适配 OpenHarmony 的边缘网关 **ECU-1170**（2025 年上市），国产芯片 + 内核级数据加密与可信执行环境 + 国密算法防护，支持 **IEC 61850、IEC 104、DNP3、DL/T 645、Modbus、OPC UA、MQTT** 等协议 —— 直接印证"OpenHarmony 边缘网关 + 多协议接入"在工业场景可行；
- **机器人/行业设备**：重庆明月湖以开源鸿蒙打造机器人产业统一"语言"；浙开鸿 EG200 面向全域鸿蒙；
- **AI 边缘网关**：开源鸿蒙赋能 RK3588 AI 边缘网关，助力国产工业智能升级。

### 4.4 对赛题的价值

- **设备侧（边缘）OS 候选**：我们的边缘网关（RK3568）可运行 OpenHarmony 标准系统，承载采集服务与协议驱动；
- **分布式软总线**：天然支持多设备互联互通，契合"不同平台下的通信效率"要求；
- **生态背书**：10 亿设备、120+ 芯片、900+ 兼容产品，证明成熟度可用；
- 开发者文档与工具链完备，适合高校团队上手（有大量教育生态）。

## 五、诚迈 HongZOS（鸿诚志远）

### 5.1 定位与背景

- **诚迈科技 2022 年 11 月 3 日于东莞松山湖发布**，是**基于 OpenHarmony 的商业发行版**，也是 **OpenHarmony 社区首个工业发行版操作系统**（诚迈官网表述）。
- 诚迈科技为开放原子开源基金会 **OpenHarmony 项目群 A 类捐赠人**，深度参与开源鸿蒙生态共建。

### 5.2 核心特性（V1.0）

针对工业、教育、能源、交通、政务等行业的 AIoT 需求定制，1.0 版本主要**破解工业设备互通难题、破除工业设备管理壁垒**：

- **多协议兼容**：兼容 **Modbus、CAN、PELCO-D** 等主流工业协议，可实现工业数据全集成与标准化管理；
- **工业软总线**：深度定制的工业互联软总线（HongZOS 工业互联软总线），打通工业全流程价值链；
- **高性能硬件编解码** + 流畅的实时视频监控（支撑工业视觉/视频应用）；
- **芯片适配**：适配瑞芯微、华为海思等芯片（官网另列展锐、龙芯、全志等国产芯片平台广泛适配）；
- 从芯片、工业软总线、通信接口、数据类型到工业协议等多个方面充分满足工业场景应用需求。

### 5.3 官方开发板与解决方案

| 开发板 | 芯片 | 定位 |
| --- | --- | --- |
| 鸿诚志远 **HCPAD-100** | 瑞芯微 RK3568（四核 64 位 A55，22nm，主频 2.0GHz） | 适配 OpenHarmony 标准系统，适用于智慧显示、视频类、工业自动化终端、**边缘计算网关** |
| 鸿诚志远 **HCA-100** | 海思 Hi3861V100 | 适配 OpenHarmony 轻量化系统，面向工业物联网传感器智能化与网联化 |

**5 大解决方案矩阵**：智能监控、工控驾驶舱、货物感应、智能机器人、行业智联软硬件 —— 与赛题功能（监控、货物感应、AGV/机器人）几乎一一对应。

### 5.4 诚迈工业软件生态（官网产品页）

- 发布了 OpenHarmony 社区首个工业发行版操作系统 HongZOS；
- 与国产芯片平台广泛适配：海思、瑞芯微、展锐、龙芯、全志等；
- 打造了**全国首个国产化替代示范工厂**；
- 拥有成熟的工业智改数转终端产品矩阵（鸿志工业设备"统一互联"打通鸿蒙生态）；
- 矿鸿生态：亮相华为中国合作伙伴大会，展示矿鸿生态成果；
- 配套产品：鸿志桌面操作系统、智能汽车操作系统（FusionOS）、智贤智能体平台（面向全行业的智能体编排平台）。

### 5.5 对赛题的价值（★ 重点）

发榜单位是诚迈科技，HongZOS 是其自研工业 OS —— 使用/适配 HongZOS 是对发榜单位技术路线最直接的响应：

1. **设备侧首选 OS**：HCPAD-100（RK3568）开发板直接可用于我们的边缘网关 + 视觉 + 采集场景，与方案硬件选型完全匹配；
2. **工业协议能力**：内置 Modbus/CAN/PELCO-D 兼容，契合"兼容大多数硬件、可开发新接口"的协议对接层设计；
3. **软总线**：多设备互联互通能力契合赛题"不同平台下的通信效率"；
4. **评审契合度**：展示"平台可快速深度融合嵌入国产 OS"，直接对标诚迈 HongZOS，最能打动发榜单位评委；
5. **资源可获得性**：可借赛事保障资源（参观诚迈国产 OS 应用场景、技术答疑）获取开发板与技术支持。

## 六、四平台对比与赛题选型建议

### 6.1 综合对比

| 维度 | 统信 UOS | 麒麟 OS | OpenHarmony | 诚迈 HongZOS |
| --- | --- | --- | --- | --- |
| 厂商/生态 | 统信软件（诚迈参投） | 麒麟软件（中国电子） | 开放原子开源基金会 | 诚迈科技（发榜单位） |
| 适合层级 | 服务器/桌面 | 服务器/工业版/嵌入式 | 设备/边缘/端侧 | **工业设备/边缘** |
| 工业专用版本 | 无明确工业版（靠生态案例） | **有工业版（PREEMPT_RT）** | 行业发行版（电鸿/矿鸿） | **本身即工业发行版** |
| 实时性 | 通用内核 | 工业版 PREEMPT_RT 实时增强 | LiteOS 实时内核（轻量设备） | 工业软总线 + 实时场景优化 |
| 协议生态 | 通用 Linux 生态（OPC UA/Modbus 需自装） | 通用 Linux 生态 + DCS 案例 | 分布式软总线 + 行业协议 | **内置 Modbus/CAN/PELCO-D** |
| 官方开发板 | 无（通用整机） | 无（生态伙伴整机） | 多厂商（研华等） | **HCPAD-100 / HCA-100** |
| 案例参考 | 鞍钢 L2、中煤煤矿、工业算力基座 | 华电 DCS、石油炼化可视化 | 电鸿、矿鸿、研华 ECU-1170 | 全国首个国产化替代示范工厂 |
| 对赛题契合度 | ★★★☆ | ★★★★ | ★★★★ | ★★★★★ |

### 6.2 选型建议（分层组合方案）

```text
┌────────────────────────────────────────────────────────┐
│  应用层（大屏/远程控制/智能体/视觉AI）                   │
├────────────────────────────────────────────────────────┤
│  平台层服务器： 统信 UOS 服务器版  或  麒麟OS(工业版)     │
│    （MQTT/TDengine/规则引擎/AI服务/Docker容器）         │
├────────────────────────────────────────────────────────┤
│  设备/边缘层： 诚迈 HongZOS（HCPAD-100/RK3568）         │
│    首选；备选 OpenHarmony 标准系统（RK3568）           │
└────────────────────────────────────────────────────────┘
```

- **平台层（服务器侧）**：优先 **麒麟 OS 工业版**（实时增强 + DCS/SCADA 背书），备选统信 UOS 服务器版（与诚迈同源、生态更广）；两者可并行适配，作为"兼容多种国产 OS"的差异化证据。
- **设备/边缘侧**：首选 **诚迈 HongZOS**（发榜单位自研、内置工业协议、官方 RK3568 开发板），同时可适配 OpenHarmony 标准系统，体现"同一套平台快速适配多种国产 OS"的能力。
- **桌面/上位机**：统信 UOS 桌面版或麒麟桌面版承载大屏/工程师站。

### 6.3 兼容性策略（对应方案"兼容大多数、不兼容开发解决"）

- 平台以 **Docker 容器化 + HAL 硬件抽象层**交付，服务器侧可在 UOS/麒麟间一键切换；
- 设备侧驱动插件框架天然兼容 HongZOS 内置的 Modbus/CAN/PELCO-D，其余协议走 Driver SDK 开发；
- 输出《国产 OS 适配报告》覆盖上述平台，作为技术先进分（50 分）的核心支撑材料。
