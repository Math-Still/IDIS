## 一、项目概述

### 1.1 项目背景

**行业背景**：铜冶炼是有色金属产业中技术密度最高、安全生产要求最严的工序之一。铜冶炼产线涵盖**原料配料 → 闪速熔炼 → PS 转炉吹炼 → 阳极炉精炼 → 浇铸**五道核心工序，现场长期面临三大结构性痛点：

- **安全风险高**：冶炼过程涉及高温熔体（1200℃+）、SO₂ 烟气、CO 与天然气（还原剂）等危险因素，危气泄漏、炉况异常、人员误入高危区等事故一旦发生，后果严重；
- **数据孤岛**：现场 DCS、PLC、工业相机、气体分析仪、AGV 等设备"七国八制"并存，协议异构，智能化应用"无米下锅"；
- **经验依赖**：炉况判断、终点判断等关键操作高度依赖老师傅经验，人才老龄化导致隐性工艺知识面临断档。

**国产化背景**：我国大量工控系统依赖国外操作系统与核心工业软件，存在供应链断供、后门漏洞、数据泄露等重大安全风险。基于国产操作系统（统信 UOS、麒麟 OS、OpenHarmony 等）构建智慧工厂安全监测控制平台，是破解"卡脖子"难题、筑牢工业安全底座的重要路径。诚迈科技深耕国产操作系统研发，并于 2022 年发布国产工业操作系统 **HongZOS**。

本团队以发榜题目为导向，以**铜冶炼智慧工厂**为落地场景，在国产操作系统底层环境上构建一套**安全监测控制平台**：以平台化的方式快速接入各类工业硬件（工业相机、摄像头、气体监测、传感器、AGV 等），兼容大多数主流厂商设备，未兼容的设备可通过插件化驱动框架快速开发接入；平台可快速深度融合嵌入国产操作系统，实现从硬件感知、平台服务到智能应用的全栈国产化闭环。

## 三、总体架构设计

平台采用**"应用层—平台层—硬件感知与协议对接层"三层架构**，国产操作系统贯穿底层，形成"硬件即插即用、服务按需挂载、应用灵活扩展"的开放平台形态：

```text
┌────────────────────────── 应用层（可扩展应用生态） ──────────────────────────┐
│ 数字员工智能体 │ 视觉AI应用 │ 数字可视化大屏 │ 远程控制台 │ 报警应急联动     │
│ 设备管理/预测性维护 │ 能耗双碳管理 │ 环保监测上报 │ MES/ERP/EMS对接 │ 报表  │
├────────────────────────── 平台层（标准化服务） ─────────────────────────────┤
│ 设备管理服务 │ 数据采集服务 │ 消息服务(MQTT) │ 时序数据库 │ 规则引擎        │
│ AI推理服务(大模型/视觉) │ 向量库/RAG │ 智能体编排 │ 低代码画布 │ 认证鉴权     │
│ 微服务治理 │ 容器/集群 │ 监控运维 │ 国密安全服务 │ 断网续传                     │
│ ── 国产操作系统底座：统信UOS / 麒麟OS（服务器侧）─────────────────────────── │
├────────────────────── 硬件感知与协议对接层（驱动插件生态） ─────────────────┤
│ 工业总线/控制: Modbus RTU/TCP · OPC UA · PROFINET · EtherNet/IP · EtherCAT  │
│ 视频/视觉: 工业相机SDK(海康/大华) · RTSP/ONVIF · GB28181                   │
│ 气体/环保: 烟气分析仪 · SO₂/CO传感器 · 天然气检漏 · HJ212                   │
│ 无线物联网: LoRa · NB-IoT · 4G/5G · ZigBee · WiFi/蓝牙                    │
│ 自研驱动SDK: 插件化驱动开发框架（新设备快速接入，无需改平台核心）            │
│ ── 国产操作系统底座：OpenHarmony / 诚迈HongZOS（设备侧边缘节点）──────────── │
└─────────────────────────────────────────────────────────────────────────────┘
```

**三层职责与关系：**

- **硬件感知与协议对接层（端）**：统一接入各类工业硬件，通过"驱动插件"将异构协议抽象为标准化设备模型，向上层提供统一的"数据 + 控制"接口。**兼容大多数厂商硬件；未内置驱动的设备，通过驱动 SDK 快速开发接入。**
- **平台层（边/云）**：提供设备管理、数据、消息、规则、AI、安全等标准化服务，向下屏蔽硬件差异，向上为应用提供 API 与运行时，**应用可快速深度融合嵌入国产操作系统**。
- **应用层（用）**：面向不同角色的工业应用生态——AI 智能体、视觉应用、可视化大屏、远程控制、管理软件对接等，均可独立开发与挂载。

## 四、硬件感知与协议对接层

### 4.1 设计目标：工业硬件"即插即用"

本层是整个平台"兼容大多数、开发解决少数"承诺的落地层：

1. **标准设备模型**：所有硬件经驱动抽象为统一的设备模型（测点、属性、命令、事件），上层应用只面对标准化接口，不感知协议差异；
2. **驱动插件化**：每个协议/设备一个独立驱动插件（Driver Plugin），独立注册、独立升级、互不影响；
3. **拖拽式接入**：提供设备接入配置界面，选择驱动 → 填写连接参数 → 自动发现测点 → 即可接入平台，无需编码；
4. **驱动 SDK**：未覆盖的硬件可通过 Driver SDK 快速开发新驱动插件，开发完成后注册进驱动市场，生态持续累积。

### 4.2 协议对接矩阵

| 类别 | 协议/标准 | 对接硬件示例 | 接入方式 |
| --- | --- | --- | --- |

| 工业总线/控制 | OPC UA | DCS、PLC（西门子/罗克韦尔/国产 PLC） | 以太网 |
| 工业总线/控制 | PROFINET / EtherNet/IP / EtherCAT | 产线控制器、伺服驱动 | 以太网/现场总线 |
| 视频/视觉 | 海康/大华 SDK | 工业相机、枪机、球机 | 以太网 |
| 视频/视觉 | RTSP / ONVIF / GB28181 | 摄像头、视频平台、国标平台 | 以太网 |
| 气体/环保 | 烟气分析仪私有/Modbus 协议 | 烟气在线分析仪（SO₂、NOx、粉尘） | 串口/以太网 |

| 自研 SDK | Driver SDK 插件框架 | 任何未内置驱动的设备 | 插件开发 |

### 4.3 驱动插件框架设计

```text
┌─ 设备接入配置台（拖拽式）─────────────────────────────┐
│  选择驱动 → 连接参数 → 测点映射 → 数据上平台 → 控制下发 │
├─ 驱动市场（内置驱动库）──────────────────────────────┤
│  modbus_rtu │ modbus_tcp │ opcua │ profinet │ gb28181 │
│  hikvision_sdk │ gas_so2 │ gas_co │ hjt212 │ lora │... │
├─ Driver SDK（新驱动开发）────────────────────────────┤
│  设备建模(Device Model) → 采集实现(Ingest) → 控制实现  │
│  (Command) → 事件上报(Event) → 注册/版本管理/热加载     │
└───────────────────────────────────────────────────────┘
```

- 驱动热加载：新增驱动无需重启平台；
- 驱动隔离：单个驱动异常不影响其他设备与平台核心；
- 断点续传：驱动层数据本地缓存，网络恢复自动补传。

### 5.3 平台层核心服务设计

**（1）设备管理服务**：设备注册、测点建模、状态监控、远程配置、固件升级、驱动插件生命周期管理。

**（2）数据采集服务**：多线程采集引擎 + 数据质量保障（滑动滤波、坏值剔除、校准补偿、时间戳统一）+ 断网续传。

**（3）消息服务**：主题分级（data / alarm / cmd / ack / log），QoS1 保证送达，TLS/国密加密。

**（4）规则引擎**：支持阈值规则、滑动窗口统计、趋势斜率预测、多条件组合、动作联动（报警/控制/通知）。

**（5）AI 服务**：模型注册、推理 API、结果回写；大模型用于智能体推理与自然语言交互，视觉模型用于图像识别，向量库支撑 RAG 知识问答。

**（6）低代码编排**：拖拽节点（数据读取、AI 模型、规则判断、执行动作、人工审批）编排为可复用"技能/流程"，工艺工程师无需写代码即可封装工艺经验。

## 八、五大核心功能详细设计（安全监测子集）

### 8.1 温湿度智能监控（精矿库/电解车间）

**数据流**：SHT30 采集 → I2C → 网关滤波校准 → MQTT 上报 → TDengine → 大屏曲线 / 规则引擎联动。

- 采集：采样周期 1s，双传感器冗余（工位 A/B）取均值；
- 控制策略：精矿库湿度偏高 → 开除湿/通风；电解车间温度偏高 → 开风机；联动响应 ≤ 2s；
- 呈现：实时值、24h 趋势、达标率、联动状态。

### 8.2 红外感应照明（车间安全照明）

**数据流**：HC-SR501 感应 → GPIO 中断 → 照明控制器 → 继电器 → LED。

- 自动模式：人员活动即开灯（≤ 500ms），离开延时关灯（30s–5min 可配置）；
- 安全管理：夜间/低照度时段自动开启高危通道照明；视觉 AI 检测到人员异常（倒地等）自动开启区域照明并报警；
- 节能统计：开灯时长、节电估算看板。

### 8.3 危气监测（SO₂/CO/天然气）

**数据流**：气体传感器 → 采集 → 校准补偿 → 规则引擎分级判定 → 报警联动 + 大屏预警。

- **分级阈值策略**：

| 级别 | SO₂（ppm） | CO（ppm） | 处置动作 |
| --- | --- | --- | --- |
| 提示 | > 2 | > 35 | 大屏黄色提示，记录日志 |
| 预警 | > 5 | > 100 | 橙色预警，开启排风，通知值班人员 |
| 报警 | > 10 | > 200 | 红色报警，排风 + 声光 + 切断非防爆电源，远程推送 |

- **联动逻辑**：报警时自动执行"排风 → 声光 → 断电"安全序列，支持远程/现场复位；
- **防误报**：双传感器交叉验证、趋势斜率确认、可配置抑制时间；
- **环保延伸**：SO₂ 烟气数据可汇总生成环保报表，按 HJ212 上报监管平台。

### 8.4 AGV 避障系统（阳极板/阴极铜搬运）

**数据流**：超声波测距 → 车载 MCU 实时决策 → PWM 调速/转向 → 电机执行；状态经网关上报平台。

| 最近障碍距离 | 决策 |
| --- | --- |
| > 60cm | 正常巡航（全速） |
| 30–60cm | 减速（50% 速度） |
| < 30cm | 急停；前向受阻时优先转向避让 |

- 多传感器融合：前向 2 路 + 侧向 2 路超声波，交叉区域取最小值；
- 失效降级：超声波异常时切换红外避障通道并上报"传感器降级"告警；
- 大屏呈现：AGV 位置（模拟轨迹）、速度、避障事件、任务状态。

### 8.5 货物感应计数（阳极板/阴极铜计数）

**数据流**：光电开关 → GPIO 中断 → 计数状态机（去抖） → 计数服务 → 产量看板 / 大屏。

- 计数逻辑：软件消抖 10ms + 两次边沿确认，每次完整遮挡-恢复记 1 件；
- 统计维度：总计数、班次计数、按产线分组；支持手动修正；
- 精度保障：浇铸线速度匹配测试，计数准确率 ≥ 99.5%。

## 九、铜冶炼特色功能设计

### 9.1 炉况监测与异常预警（熔炼工·守炉）

- 秒级扫描炉温、炉压、SO₂、冷却水流量等关键参数（经 OPC UA/Modbus 对接 DCS/PLC）；
- 异常趋势检测：区分"正常波动"与"早期故障征兆"，分级推送；
- 联动调度工·全局，提前预告影响下游进料节奏的工况变化。

### 9.2 终点判断（吹炼工·判终 / 精炼工·还魂）

- 多模态融合：温度曲线 + SO₂ 浓度曲线 + 工业相机火焰图像（RGB 特征）三路信号；
- 机理约束 + 数据驱动：以铜锍氧化还原热力学约束限定物理合理范围，深度学习模型在约束内预测终点概率；
- 人工审批闭环：中风险操作须炉长确认后写入 DCS，全程留痕审计。

### 9.3 全流程协同调度（调度工·全局）

- 汇聚五工序智能体实时预测，构建全产线状态视图；
- 预测各工序完成时间，提前计算节奏匹配方案（如 A 转炉距完工 18 分钟、B 阳极炉需 22 分钟预热 → 提前 4 分钟通知 B 预热）；
- 每班次生成协同调度报告。

### 9.4 安全行为视觉识别

- 安全帽检测、危区闯入、人员倒地：YOLO 轻量模型边缘推理；
- 联动：闯入报警 + 区域照明自动开启 + 红外联动 + 大屏高亮。

### 10.1 通信协议与效率优化

| 通道 | 协议 | 优化手段 |

| 硬件—网关 | Modbus RTU/TCP、OPC UA 等 | 批量读寄存器、突发模式、总线轮询分片 |
| 网关—平台 | MQTT over TLS/国密 | QoS1、主题分级、消息批量打包 |
| 平台—大屏 | WebSocket | 增量推送、二进制压缩帧、心跳保活 |
| 平台—远程端 | HTTPS + WebSocket | 指令幂等、超时重试、审计留痕 |

**量化目标**：单帧报文 ≤ 1KB；消息吞吐 ≥ 5000 条/s；端到端时延本地 ≤ 200ms、远程 ≤ 1s。

### 10.2 数据质量保障

- 滑动平均/中值滤波：抑制尖峰毛刺；
- 坏值剔除：越界值、跳变值自动剔除并打标记；
- 校准补偿：电化学气体传感器温湿度补偿、零点漂移校正；
- 时间戳统一：边缘网关 NTP 校时 + 本地高精度时钟兜底。

### 10.3 实时性保障

1. 内核级：设备侧启用实时调度（OpenHarmony LiteOS 实时任务、HongZOS 实时补丁），危气采集最高优先级；
2. 进程级：实时优先级 + CPU 绑核，避免调度抖动；
3. 数据链路：内存映射 + 无锁队列（SPSC）零拷贝传递；
4. 端到端监控：采集时延、队列积压、消息时延全程打点，大屏展示链路健康度。

### 10.4 数据存储与断网续传

- 时序数据：TDengine（国产时序数据库），按设备/测点建模，保留 90 天热数据 + 冷归档；
- 断网续传：边端本地缓存（环形队列 + SQLite），网络恢复按序补传，保证数据完整性；
- 数据导出：CSV/Excel 报表，按班次/日/月维度。

## 十一、安全设计

### 11.1 系统安全

- 基于国产 OS 安全特性（SELinux/AppArmor 可选、最小化服务、补丁管理），关闭不必要端口；
- 账户安全：密码策略、登录失败锁定、双因素认证（可选）。

### 11.2 数据安全

- 传输加密：MQTT over TLS；可选国密 SM2/SM4；
- 存储加密：敏感配置与用户数据加密存储，数据库最小权限；
- 数据完整性：关键数据国密 SM3 校验，审计日志只追加、不可删改。

### 11.3 通信安全

- 设备接入需注册认证（设备证书/Token），未授权设备禁止接入；
- 数据通道与指令通道隔离（data/cmd 主题），指令带序号防重放。

### 11.4 工业控制安全

- 权限分级（管理员/操作员/观察员），高危指令二次确认；
- 联动互锁：报警状态锁定部分危险操作（如禁止解除排风）；
- 应急预案：平台离线时边端自治，本地规则继续执行，基本安全功能不失效；
- 全程审计：技能调用、指令下发、审批过程、执行结果全程留痕。

## 十二、创新点分析

### 12.1 底层环境创新（国产 OS 全栈适配）

- 平台可快速深度融合嵌入国产操作系统，同一套业务代码经 HAL 适配层运行于统信 UOS、麒麟 OS、OpenHarmony、诚迈 HongZOS 多平台；
- 形成可复用的国产 OS 工业适配方法论与真机适配报告；
- 设备侧采用 OpenHarmony/HongZOS 构建工业边缘节点，探索"工业 OS + 边缘智能"国产化路径。

### 12.2 硬件接入创新（驱动插件生态）

- **兼容大多数**：内置工业总线（Modbus/OPC UA/PROFINET/EtherNet/IP/EtherCAT）、视频视觉（海康/大华 SDK、RTSP/ONVIF/GB28181）、气体环保（烟气分析仪、SO₂/CO 传感器、HJ212）、无线物联网（LoRa/NB-IoT/4G/5G/ZigBee）等主流协议驱动；
- **开发解决少数**：Driver SDK 插件化开发框架，新设备快速接入，无需修改平台核心；
- "驱动市场"随生态持续累积，形成"驱动越丰富→设备接入越容易→应用越繁荣"的正向飞轮。

### 12.3 平台服务创新（服务化架构）

- 平台层服务化（消息、时序、规则、AI、向量、容器、安全），应用可挂载可卸载；
- 低代码编排画布：工艺工程师无需专职 AI 团队即可封装工艺技能；
- 多智能体协作：从"单工序局部最优"到"全产线全局最优"。

### 12.4 算法创新（新质生产力）

- 机理约束 + 数据驱动的终点判断模型：热力学约束限定物理范围，杜绝违反物理规律的预测；
- 趋势斜率 + 滑动窗口的危气预测预警：变"超标报警"为"趋势预警"；
- 多传感器融合 AGV 避障：超声波 + 红外冗余，分级决策；
- 视觉 + 数值多模态融合：火焰图像与 SO₂/温度曲线联合判断。

### 12.5 场景创新

- 以铜冶炼真实产线"监测—预警—控制—统计"闭环为主线，五道工序数字员工 + 安全监测子集一体化；
- 平台形态具备向铅、锌、镍等其他有色冶炼品种横向扩展的产业化潜力。
