## 逐页大纲（正文 15 页）

### 1 题目理解与需求分析（约 40 秒）

- **发榜方核心诉求拆解**（一页讲清"我们要解决什么问题"）：
  1. 以国产操作系统为底层环境（统信 UOS / 麒麟 OS / OpenHarmony 等）；
  2. 实现五大功能：温湿度监控、红外照明、危气监测、AGV 避障、货物计数；
  3. 兼顾采集速度与精度、跨平台通信效率；
  4. 数字可视化大屏 + 远程控制。
- **我们的应答**：不做一个"单点工具"，而是一个**应用驱动的国产化平台**——五大功能是应用层的安全监测域，平台可扩展、可复制。
- **视觉**：题目要求 → 我们方案的对应关系表。

### 2 场景痛点：铜冶炼安全生产之困（约 40 秒）

- 四大痛点（每条一句话 + 一个数据）：
  1. **危气风险高**：SO₂/CO/天然气泄漏，人工巡检分钟级响应，联动处置滞后；
  2. **协议异构**：DCS/PLC/相机/气体仪"七国八制"，数据孤岛；
  3. **国产 OS 适配难**：国外生态开发、迁移成本高、真机跑不起来；
  4. **有平台无应用**：数据接进来却没有可用应用，智能化停在看板层。
- **收尾**："这些痛点的共同答案，是一个'应用丰富、插上就用、换系统就跑'的国产化平台。"

### 3 总体方案：三层架构（约 40 秒）

- **核心图**：平台总体架构图（SVG 版）
- 三层一句话讲清：
  - **应用层**（价值核心）：安全监测/可视化控制/智能分析/生产运营/设备能源/知识支撑 六大业务域；
  - **平台层**：数据/消息/规则/AI 标准化服务；
  - **硬件协议对接层**：驱动插件生态，兼容大多数、开发解决少数；
  - **国产 OS 贯穿底层**：麒麟 / 统信 / OpenHarmony / 诚迈 HongZOS。
- **金句**："硬件是插头，平台是管线，应用是电器——我们做的是整套水电系统，而不是单个灯泡。"

### 4 应用层全景：六大业务域（约 40 秒）

- **核心图**：应用层全景图（SVG 版）
- 六大业务域速览：
  1. 安全监测域（题目必做五大功能）★
  2. 可视化与控制域（大屏/远程/报警联动）★ 题目要求
  3. 智能分析域（AI 智能体 + 视觉 AI）
  4. 生产运营域（报表 + 人员安全）
  5. 设备与能源域（设备管理 + 能耗双碳）
  6. 知识支撑域（工艺知识库 RAG）
- **强调**："应用按需挂载、随需求生长——新增业务场景只需挂载新应用，不改平台、不动设备。"

### 5 安全监测域：五大功能（题目必做，约 1 分钟）★

- 五个功能卡片，每个给出"场景映射 + 关键指标"：
  | 功能 | 铜冶炼场景 | 关键指标 |
  |---|---|---|
  | 温湿度监控 | 精矿库/电解车间 | 采集 ≤1s、联动 ≤2s |
  | 红外感应照明 | 车间安全照明 | 开灯 ≤500ms |
  | 危气监测 | SO₂/CO/天然气 | 链路 ≤500ms、联动 ≤1s |
  | AGV 避障 | 阳极板/阴极铜搬运 | 避障 ≤100ms |
  | 货物计数 | 阳极板/阴极铜产量 | 准确率 ≥99.5% |
- **演示提示**：本页为实物演示预告页，翻页后直接切到沙盘实机演示。

### 6 危气监测：端到端数据流（约 40 秒）★ 技术深度

- **核心图**：危气监测数据流图（SVG 版）
- 四步链路：传感器感知 → 驱动接入 → 平台处理（滤波校准/三级阈值/趋势预测）→ 联动处置（排风→声光→断电）
- 三级阈值策略（CO 为例）：提示 >35 / 预警 >100 / 报警 >200
- **强调实时性**："从气体泄漏到联动处置，秒级闭环，比人工巡检快一个数量级。"

### 7 智能应用：AI 智能体 + 视觉 AI（约 40 秒）

- AI 智能体（多类，数字员工只是其中一类）：工艺数字员工 / 设备预测性维护 / 能耗优化 / 环保合规 / 安全巡检
- 视觉 AI：火焰识别（辅助终点判断）、安全行为识别（安全帽/危区闯入/人员倒地）
- 技术点：ReAct 智能体范式、多智能体跨工序动态决策、RK3568 NPU 边缘推理 ≥15fps
- **金句**："平台不绑定某一种 AI——新场景只需开发新智能体应用。"

### 8 平台层：标准化服务支撑（约 30 秒）

- 服务清单（快讲）：设备管理 / 时序数据 TDengine / 消息 MQTT / 规则引擎 / AI 推理（大模型+视觉）/ 向量检索 / 低代码画布 / 国密安全 / 容器集群
- **强调**："平台层向下屏蔽硬件差异，向上为应用提供标准化服务，这是应用生态能生长的土壤。"
- 视觉：平台层服务卡片图。

### 9 硬件协议对接层：驱动插件生态（约 40 秒）

- **核心卖点**：兼容大多数、开发解决少数
- 四类协议矩阵：工业总线（Modbus/OPC UA/PROFINET…）｜视频视觉（海康/大华、GB28181）｜气体环保（烟气分析仪、HJ212）｜无线物联网（LoRa/NB-IoT/4G/5G）
- Driver SDK：未内置驱动的新设备，快速开发插件接入，不改平台核心
- **金句**："新增一台设备 = 注册一个驱动插件；新增一个场景 = 挂载一个应用。边际成本趋近于零。"

### 10 国产 OS 适配与真机验证（约 1 分钟）★ 技术先进核心页

- **四层适配方法论**：HAL 抽象层 → 容器化交付 → 构建适配矩阵 → 性能对比验证
- **真机证据**：麒麟 OS（工业版）/ 统信 UOS / OpenHarmony / 诚迈 HongZOS 真机部署截图
- **强调与发榜单位契合**："设备侧首选诚迈 HongZOS（RK3568 官方开发板），平台可快速深度融合嵌入国产操作系统——这正是诚迈最关心的'国产 OS 工业落地'问题。"
- 视觉：真机截图 + 《国产 OS 适配报告》封面。

### 11 核心指标与多平台对比测试（约 40 秒）★ 用数据说话

- 对比表：通用 OS 基线 vs 麒麟 / 统信 / HongZOS（采集周期稳定性、危气联动响应、消息吞吐、大屏刷新时延）
- **强调**："每一项优化都基于实测数据，国产 OS 环境下的监测精度与速度达标，跨平台通信效率经同口径压测验证。"
- 视觉：对比数据表 + 折线/柱状图。

### 12 创新点：三大技术壁垒（约 40 秒）

- 壁垒一：**应用生态机制**（六大业务域开箱即用 + 应用商店 + 低代码画布 + 开放 API）——解决"有平台无应用"；
- 壁垒二：**驱动插件生态**（即插即用 + Driver SDK）——解决"协议异构"；
- 壁垒三：**国产 OS 适配方法论**（HAL + 容器 + 适配矩阵 + 真机验证）——解决"适配难"。
- **金句**："壁垒不是代码，而是'能适配、能兼容、能承载应用'的系统能力。"

### 13 现场演示：沙盘 + 大屏 + 远程控制（约 2 分钟）★ 功能完整冲刺

- **演示脚本（5 分钟标准流程）**：
  1. 平台登录 + 大屏总览（30s）；
  2. 危气泄漏触发：传感器读数上升 → 大屏弹窗报警 → 声光报警 → 排风自动开启（60s）★核心演示；
  3. 远程控制：手机端远程开启排风/报警复位（30s）；
  4. 五大功能快闪：温湿度联动 / 红外照明自动开关 / AGV 避障 / 光电计数（30s）；
  5. AGV 遇障急停演示（20s）。
- **视觉**：实物沙盘 + 大屏同屏；故障注入器现场制造"危气超标"。

## 答辩预案（擂台赛 Q&A 高频问题）

| 评委可能提问 | 应答要点 |
|---|---|
| 国产 OS 真机验证是怎么做的？ | Docker 模拟开发加速迭代 → 麒麟/UOS/HongZOS 真机部署 → 运行截图 + 适配报告（现场展示截图） |
| 五大功能的传感器精度如何保证？ | 双传感器冗余 + 滤波/校准/坏值剔除 + 标准仪表比对测试（计数 99.5%、温湿度 ±0.5℃） |
| 与诚迈 HongZOS 的契合点？ | 设备侧采用 RK3568 + HongZOS，内置 Modbus/CAN 协议，平台可深度融合嵌入国产 OS |
| 平台相比通用工业互联网平台强在哪？ | 以应用层为价值核心：六大业务域开箱即用，非"重连接、轻应用"的看板平台 |
| 数据安全怎么保证？ | TLS/国密加密、设备认证、权限分级、高危指令二次确认、审计留痕 |
| 现场演示失败怎么办？ | 演示脚本预演多次 + 冗余设备 + 模拟数据源兜底（软件仿真模式） |
